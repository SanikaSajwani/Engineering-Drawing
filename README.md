# Engineering-Drawing
Engineering Drawing - EE Semester One

Welcome to the Engineering Drawing repository. This repository contains all the labs, assignments, projects, and a lab project related to the course. Below is an overview of the content, including a brief component description.

Table of Contents
- Labs
- Assignments
- Projects

## Labs

### Lab 1: Introduction to Engineering Drawing
- Overview of line drawing tools and techniques.

### Lab 2: Introduction to AutoCAD & XY Coordinate System
- Introduction to AutoCAD software and its interface.
- Understanding the XY coordinate system for accurate placement and drafting in AutoCAD.

### Lab 3: The Drawing Commands
- Introduction to basic drawing commands in AutoCAD (e.g., line, circle, arc, polygon).
- Practical exercises in creating simple shapes and patterns.

### Lab 4: The Modifying Commands
- Learning AutoCAD modification tools such as move, rotate, scale, trim, extend.
- Exercises to edit and modify existing drawings efficiently.

### Lab 5: Object Snaps and Properties
- Understanding object snaps and how to use them for precision.
- Modifying object properties like layers, line types, and colors to manage drawing complexity.

### Lab 6: Isometric & Axonometric Projections
- Introduction to 3D projection techniques such as isometric and axonometric projections.
- Creating 3D-like representations in AutoCAD from orthographic views.

### Lab 7: Introduction to 3D & Wireframe Models
- Understanding 3D modeling fundamentals in AutoCAD.
- Creating wireframe models to visualize designs in three dimensions.

### Lab 8: Primitive Solids
- Creating and modifying basic 3D solid objects such as cubes, cylinders, cones, and spheres.
- Using Boolean operations (Union, Subtract, Intersect) to combine and edit solids.

### Lab 9: 3D Solid Modeling and Boolean Operations
- Introduction to Boolean operations to combine, subtract, and intersect objects.
- Practical exercises using cylinders, cones, boxes, and pyramids to demonstrate solid manipulation.
- Advanced SLICE command techniques for object division.
- Troubleshooting AutoCAD modeling errors (Error Code: 85018).

### Lab 10: Revolve, Sweep, and Loft Commands
- Understanding advanced 3D commands: Revolve, Sweep, and Loft to create complex shapes.
- Practical exercises in designing rotational and freeform models.

### Lab 11: Combining It All - Designing a Mini Project
- Implementing all learned skills into a comprehensive design project.
- Using multiple tools, commands, and modeling techniques in a real-world scenario.

### Lab 12: Manual Drawing - Drawing Projections of 3D Objects on Paper
- Practicing hand-drawn orthographic and isometric projections.
- Enhancing spatial visualization skills without digital assistance.

### Lab 13: Manual Drawing - Drawing the World on Paper
- Freehand and technical sketching of real-world objects.
- Strengthening visualization and drafting skills.

### Lab 14: 3D Printing
- Understanding the workflow from CAD modeling to 3D printing.
- Exporting designs for additive manufacturing and material considerations.

## Assignments
Assignment: Writing Your Name with Line and Polyline Commands
Task: Write your name using AutoCAD’s LINE and PLINE commands, with a double-text effect for bold lettering.

## Lab Project: Engineering Design Challenge
As a culminating lab project, students will apply all the skills learned throughout the course to design and create a real-world 3D model using AutoCAD.

Project Requirements:
Step 1: Concept Development
- Choose an object to design and model.
- Sketch rough ideas and design variations.

Step 2: 3D Modeling in AutoCAD
- Create a detailed 3D model using extrusions, lofts, sweeps, and revolutions.
- Use layers, object snaps, and constraints to enhance precision.

Step 3: Final Presentation
- Present the final design, workflow, and challenges faced.
- Submit the digital model.
